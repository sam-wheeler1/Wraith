# Engineering decision log

Keep short numbered records here when an important engineering trade-off is decided. A decision record should link back to the calculations, geometry revision, measurements, and constraints behind it.

## Suggested naming

`0001-wing-configuration.md`, `0002-inlet-architecture.md`, etc.

## Decision record structure

- **Status:** Proposed / Accepted / Superseded
- **Context and design objective**
- **Options considered**
- **Evidence:** calculations, figures, tests, simulations
- **Decision and reasoning**
- **Trade-offs and assumptions**
- **What would cause reconsideration**

Do not record a provisional choice as final unless its supporting design analysis exists.
