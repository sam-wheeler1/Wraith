# Wraith project status

**Repository inventory date:** 2026-10-23

This page distinguishes *repository evidence* from *work described outside GitHub*. It deliberately avoids treating uncommitted work as verified or flight-qualified.

## Confirmed present in this repository

- MATLAB script estimating altitude-dependent freestream conditions and EDF mass flow for inlet/duct CFD boundary conditions. See [analysis](../analysis/README.md).
- Project summary and documentation framework.

## Work discussed but not yet archived here

The project has included discussions or local progress on a 90 mm-class EDF, inlet and conventional nozzle CAD, CFD iteration, a thrust-stand concept, Arduino/Python data acquisition, pressure sensors, and potential high-angle-of-attack inlet research.

**These items are not confirmed as committed, tested, or finalized by this repository.** Add source files, test evidence, version information, and decisions as available.
